# Airbnb-Performance-Dashboard-Power-BI

This project is an interactive Power BI Dashboard built using Airbnb listing data to analyze business performance across multiple cities. The dashboard provides insights into listings, hosts, pricing, ratings, customer reviews, market share, and seasonal booking trends to help understand Airbnb's global performance.

📊 Dashboard Highlights
📍 Total Listings: 279,712
🌍 Cities Analyzed: 10
👤 Hosts: 182,024
🏠 Property Types: 144
⭐ Reviews: 5.37M+

📈 Key Features
Executive KPI Dashboard
Listing Growth Trend (2008–2020)
Market Share by City
Average Price by Property Type
City-wise Ratings Analysis
Monthly Review Seasonality
Host Trust & Verification Analysis
Interactive Filters and Drill-downs

💡Business Insights
Paris has the highest number of Airbnb listings and reviews.
Paris, New York, and Sydney contribute nearly half of all listings and 59% of total reviews.
Airbnb experienced rapid growth until 2015 before slowing due to regulatory changes, followed by a COVID-19 impact in 2020.
Hotel rooms have the highest average listing price.
Mexico City and Rio de Janeiro received the highest overall ratings.
More than two-thirds of hosts are fully verified.
